# Исправлена загрузка рекомендаций

- Рекомендации появляются из уже полученных страниц, без ожидания завершения целой подборки. У источника показывается отметка «Подборка загружена частично».
- Исправлена очередь: сохранение страницы больше не перемещает начатую подборку в конец списка. Обнаружение следующих материалов чередуется с загрузкой книг.
- Кнопка «Проверить сейчас» продолжает незавершённую загрузку и не сбрасывает промежуточные страницы. Новая сверка начинается только после окончания предыдущей.
- Появился подробный прогресс: текущая подборка, полученное число книг, количество загруженных страниц и частично заполненных материалов.
- Убраны лишние минутные простои между порциями. Защитный интервал между запросами и паузы при ограничениях LiveLib сохранены.
- Антологии без обычной ссылки на автора больше не пропускаются: подборка может загрузиться полностью, без зависания на «91 из 92».

Уже полученные в 2.2.0 данные сохраняются и могут сразу использоваться для рекомендаций. Очищать каталог не требуется. История чтения, конвертер, параметры конвертации и структура выходных файлов не изменены.
