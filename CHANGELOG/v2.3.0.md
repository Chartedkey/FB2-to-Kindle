# Отметки о прочтении и циклы в библиотеке

- Нажмите «Прочитал» рядом с книгой, чтобы добавить её в историю. Оценка необязательна, дату можно указать с точностью до дня, месяца или года либо оставить неизвестной.
- При добавлении книги в «Моём чтении» доступны подсказки из библиотеки с именами авторов. Выбранная книга связывается с записью в истории. Книги вне библиотеки можно добавить вручную.
- Кнопка «Циклы» на карточке автора группирует его книги по циклам. Книги с известными номерами идут по порядку, остальные отмечены отдельно. Счётчики статусов показывают количество книг выбранного автора.
- Название цикла и номер книги можно исправить в приложении. Кнопка «Найти циклы онлайн» ищет однозначные совпадения в Викиданных. Ручные исправления имеют приоритет и хранятся отдельно от файлов FB2.
