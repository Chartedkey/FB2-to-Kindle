Первая версия с готовым exe — Python больше не нужен.

**Новое**
- Вкладка «Библиотека»: авторы и книги из папки FB2, статус конвертации каждой книги («Готово», «Не сконвертирована», «FB2 изменился»), обложки, серия, год, жанр, аннотация.
- Конвертация одной книги, всех недостающих у автора или нескольких авторов сразу.
- Справки об авторах и описания книг из Википедии (можно выключить).
- Новое окно на Qt, книги можно перетаскивать в окно мышкой.
- Кнопка «Проверить обновления».

**Изменения**
- По умолчанию книги помечаются как «Документы» — так Kindle показывает обложки.
- Исправлена ошибка `fbc-panic.log` при одновременной конвертации нескольких книг.
