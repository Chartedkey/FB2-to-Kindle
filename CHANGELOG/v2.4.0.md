# Полная библиотека и варианты изданий

- Новая вкладка «Полная библиотека» открывает локальную ZIP-коллекцию по индексу MyHomeLib `.inpx`. Поиск работает по автору и названию.
- На карточке автора видно, какие произведения и конкретные варианты уже есть в личной библиотеке. Переводы и издания можно раскрыть и сравнить по сведениям из FB2.
- Можно добавить один или несколько вариантов. Программа извлекает их отдельными FB2 в папку автора, обновляет личную библиотеку и сохраняет существующие файлы.
- Добавленные книги можно открыть в назначенной читалке. У импортированных вариантов разные имена выходных файлов Kindle, поэтому их можно конвертировать отдельно.
