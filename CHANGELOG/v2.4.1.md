# Поиск, языки и обложки в полной библиотеке

- Поиск по имени автора, в том числе по запросу «курт вон», открывает весь список его произведений. Поиск по названию по-прежнему показывает подходящие книги.
- Добавлен фильтр по языку. Обложка выбранного издания загружается из ZIP до добавления книги.
- Имена авторов отображаются в порядке «имя фамилия».
- Новые FB2 сохраняются под названием книги. Если оно уже занято, программа добавляет номер варианта, например «(вариант 2)». Старые файлы с пометкой INPX сохраняют свои имена.
