**Обновление внутри программы**
- «Проверить обновления» показывает, что нового, и по кнопке «Обновить» сама скачивает новую версию, проверяет её, обновляется и перезапускается. Заходить на GitHub больше не нужно.
- Настройки, библиотека и готовые книги при обновлении сохраняются. Если что-то пойдёт не так, остаётся прежняя версия.
- На эту версию нужно перейти один раз вручную; следующие обновления ставятся из программы.

**Новая иконка**
- Иконка с книгой и Kindle на прозрачном фоне.
- Отдельные упрощённые версии для мелких размеров и все промежуточные размеры для масштаба экрана 125 % и 150 % — на панели задач иконка остаётся чёткой.
