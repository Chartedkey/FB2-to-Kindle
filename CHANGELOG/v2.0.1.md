**Автор из названия папки**
- В библиотеке автор теперь берётся из названия папки, а не из FB2. Разные написания одного автора в книгах («Сэмюэл», «Самуэль», «Беккетт») больше не дают несколько авторов.
- Имя и фамилия меняются местами: папка «Мьевилль Чайна» → автор «Чайна Мьевилль», в том числе в названии папки для Kindle. Фамилию из нескольких слов отделите запятой: «Ле Гуин, Урсула».
- Книги, которые лежат прямо в корне библиотеки, по-прежнему берут автора из FB2.
- Переключатель «Имя автора: из названия папки / из книги» над списком авторов.
- На вкладке «Конвертация» поле «Папка автора» заполняется из названия добавленной папки.

**Сброс данных**
- «Сбросить данные библиотеки» — в меню у кнопки «Обновить» (стрелка справа). Программа забывает сохранённые сведения о книгах, обложки и данные Википедии и перечитывает библиотеку. Книги и готовые файлы для Kindle не меняются.
