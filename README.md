# FB2 → Kindle

Программа для Windows: превращает книги FB2 в формат KFX для Kindle, раскладывает их по папкам авторов и ведёт библиотеку — видно, какие книги уже сконвертированы.

## Скачать

Откройте [страницу выпусков](https://github.com/Chartedkey/FB2-to-Kindle/releases/latest), скачайте `FB2-Kindle-…-windows.zip`, распакуйте в любую папку и запустите **FB2 Kindle.exe**. Python и другие программы не нужны.

Конвертер [fb2cng](https://github.com/rupor-github/fb2cng) уже лежит в папке `fbc` рядом с программой.

## Обновления

Нажмите **Проверить обновления** внизу окна. Если есть новая версия, программа покажет, что изменилось, и по кнопке **Обновить** сама скачает её, обновится и перезапустится. Настройки, библиотека и готовые книги сохраняются.

## Вкладка «Конвертация»

1. **Добавить файлы…**, **Добавить папку…** или просто перетащите книги в окно. Подходят `.fb2` и `.fb2.zip`.
2. Выберите, куда сохранить:
   - **Папка автора** — все книги попадут в одну папку, имя автора подставляется из книг само;
   - **Отдельная папка для каждого автора**;
   - **Отдельные файлы**, без папки.
3. Нажмите **Конвертировать**. В колонке «Статус» видно, что происходит с каждой книгой; двойной щелчок по ошибке показывает подробности.

```
Для Kindle\
└── Чайна Мьевилль\
    ├── Кракен.kfx
    └── Шрам.kfx
```

## Вкладка «Библиотека»

1. Выберите **папку с книгами FB2** и **папку с книгами для Kindle**.
2. Слева — авторы, в середине — книги выбранного автора со статусом:
   **Готово**, **Не сконвертирована** или **FB2 изменился** (файл поменялся после конвертации).
3. Справа — обложка, серия, год, жанр и аннотация книги.
4. Конвертировать можно одну книгу, все недостающие у автора или сразу нескольких авторов: отметьте их галочками и нажмите **Сконвертировать выбранных**.

Автор берётся из названия папки, в которой лежит книга: папка «Мьевилль Чайна» → автор «Чайна Мьевилль» (первое слово считается фамилией и переносится в конец). Фамилию из нескольких слов отделите запятой: «Ле Гуин, Урсула». Книги прямо в корне библиотеки берут автора из FB2. Над списком авторов можно переключиться на «из книги (FB2)».

Новые книги появляются после кнопки **Обновить**. Если что-то выглядит странно, в меню у этой кнопки есть **Сбросить данные библиотеки** — программа перечитает все книги заново (сами книги и готовые файлы не меняются).

Если включена галочка **Википедия**, программа подгружает справку об авторе и описание книги, когда в FB2 нет аннотации. Загруженное сохраняется, поэтому каждый запрос делается один раз.

Первое чтение большой библиотеки занимает время, потом она открывается сразу.

## Моё чтение

Во вкладке **«Моё чтение»** можно вести списки книг, ставить оценки и сохранять заметки. В библиотеке это доступно через **«Статус чтения и оценка…»**. Отметки не зависят от конвертации. Рядом с книгами показываются обложки из FB2 или данных LiveLib; при отсутствии изображения — заглушка.

Не помните, когда прочитали книгу? Укажите только месяц, год или **«Прочитано ранее — дата неизвестна»**. Программа не будет придумывать даты. Доступны статистика, квартальные и годовые итоги, ручное добавление книг без файла и массовая отметка ранее прочитанного.

Рекомендации подбираются из вашей библиотеки или редакционных материалов `Redakciya_LiveLib`. Каталог загружается постепенно по кнопке, с паузой и сохранением прогресса. Уже полученные подборки работают без интернета. История чтения и оценки в LiveLib не отправляются.

[Как работает трекер, загрузка каталога и резервные копии](docs/reading.md).

## Как закинуть книги на Kindle

Подключите Kindle кабелем, откройте **Этот компьютер → Kindle → Internal Storage → documents** и перетащите туда папку автора.

По умолчанию книги помечаются как **«Документы»** — так Kindle сам показывает их обложки. Изменить можно в «Дополнительно…».

## Интернет

Программа выходит в интернет только для трёх вещей: сведения из Википедии (можно выключить), кнопки **Обновить fb2cng** и **Проверить обновления** (и скачивание обновления, если вы нажали «Обновить»). Книги и данные о них никуда не отправляются.

Настройки и кэш библиотеки хранятся в `%APPDATA%\FB2Kindle`.

## Для разработки

```
pip install -r requirements.txt -r requirements-dev.txt
python tools/get_fbc.py fbc windows
python run.pyw
python -m pytest tests
python tools/make_version_info.py && python -m PyInstaller --noconfirm FB2Kindle.spec
```

Новая версия: поменять `__version__` в `src/fb2kindle/__init__.py` и описать изменения в `CHANGELOG/vX.Y.Z.md`. После отправки в `main` GitHub соберёт exe и сам создаст выпуск `vX.Y.Z`.
